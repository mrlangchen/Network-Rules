# 重复规则处理记录

原始 15,071 条；保留 13,204 条有效规则；注释 1,867 条。
原先跨目标重复 1,790 组，另有同目标重复；合计 1,810 组相同条件。
相较原顺序，有 0 组相同条件改用了另一个目标。

## 决策

1. 完全相同的规则类型、匹配值按 REJECT > PROXY > DIRECT 选一条；本批相同条件的 no-resolve 等选项全部一致。
2. REJECT 类：REJECT、广告拦截、应用净化。DIRECT 类：DIRECT、全球直连。其他服务组与节点选择归 PROXY 用途类。
3. 同为 PROXY 类时，专用服务组优先于通用节点选择；仍相同时保留原先第一条。
4. 低优先级及同级剩余项留在原所属 list，前加 #，注明保留项的原序号及目标。未删除原记录。
5. 分类依据是规则目标用途，不是运行时组内选项。哔哩哔哩、网易音乐等仍可选择 DIRECT，广告组仍可手动放行；上述类别不是强制锁定最终出口。
6. 父子域名、不同长度 CIDR、DOMAIN-KEYWORD 与其他类型的交集不属于本次“相同条件”去重。额外记录了 1,346 对父子域名/网段包含关系，未宣称消除了所有语义重叠。

## 附带修正
